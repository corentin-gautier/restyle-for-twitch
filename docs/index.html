Twitch, with the noise turned down

Restyle for Twitch is a free Chrome extension that quiets the busy parts of twitch.tv and gives the content more room. Nothing is added, and nothing works differently.

Install the extension View on GitHub

What the extension changes

It is a stylesheet laid over twitch.tv. Turn it off in one click and Twitch is back as it was.

  • Sidebar and top barSmaller, quieter, no stories
  • Home, Browse, SearchNo carousel, clearer cards
  • Channel pagesFramed player, one column
  • ChatMuted until hovered
  • Menus and dialogsFlat, with borders
  • Your coloursAccent, background, spacing
Navigation

A quieter sidebar and top bar

  • Smaller rows, small-caps section headers, viewer counts aligned to the right.
  • No stories, no hover cards, no "For You" header.
  • More room in the top bar, a pill-shaped search field, dimmed icons.
HomeBrowseSearch

Cleaner pages

  • The autoplaying carousel is removed from the home page, and its video is paused.
  • Large shelf titles, the same on the home page, channel pages and under a video.
  • Rounded thumbnails, and cards that put the streamer's name first.
  • Tags and categories become small chips in your accent colour.
Channel

A framed player

  • The player is inset and rounded, with the stream information in a centred column below it.
  • Offline channels, videos and clips follow the same column and the same cards.
  • Panels line up on the column instead of floating in the middle.
Chat

A calmer chat

  • Muted messages that return to full contrast on hover, and a soft fade at the top.
  • The gifter leaderboard above the messages is hidden.
  • Chat replay on videos gets the same treatment as the live chat.
MenusDialogs

Flat menus and dialogs

  • Borders instead of shadows, and a dimmed backdrop behind dialogs.
  • Filter and sort menus share one row size and one inner margin.

Settings

Click the extension's icon. Changes apply at once, without reloading the page.

Enable on TwitchTurns the whole restyle on or off.
SpacingThree densities: compact, airy, very airy.
Accent colourThe colour of links, tags and highlights.
Plain chatHides chat badges and shows every username in the text colour.
Background colourThe page colour. Sidebars, chat, menus and text colours are derived from it. Reset it to follow Twitch's own light or dark theme.

Install the Chrome extension

It is not on the Chrome Web Store yet. Until then, load it from the source. Requires Chrome 120 or later.

  1. Download or clone the repository.

    git clone https://github.com/corentin-gautier/restyle-for-twitch.git

  2. Open chrome://extensions and turn on Developer mode.

  3. Click Load unpacked and select the repository folder.

Twitch changes its markup without notice, so an update on their side can break part of the restyle. If something looks wrong, open an issue with a screenshot and the page's address.

Privacy

The extension only runs on twitch.tv. It collects nothing and sends nothing anywhere. Its one permission, storage, is used to remember your settings.
