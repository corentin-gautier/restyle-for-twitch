# Changelog

All notable changes to this project are documented in this file. From 1.1.1 on, it is generated by [standard-version](https://github.com/conventional-changelog/standard-version) from [Conventional Commits](https://www.conventionalcommits.org/).

## [1.1.0](https://github.com/corentin-gautier/restyle-for-twitch/compare/v1.0.1...v1.1.0) (2026-10-10)

### Features

* restyle the offline channel page, the video page and its chat replay
* restyle search results, category headers, the schedule caption and the "Featured Clips" card
* restyle the Subscribe and Gift a Sub panels, the "Chapters" button and its popup
* use the same shelf titles and cards on the home page, channel pages and under a video
* give all filter and sort menus the same inner margins, and right-align "Filter By"
* inset the sign-up banner shown to logged-out visitors
* translate the popup (English and French) and add a reset for the accent colour

### Fixes

* hide the gifter leaderboard above the chat again
* lay channel panels out on the full width of the column
* keep the progress bar of chat highlight cards inside the card
* round the cut-out of the gradient frame on shared-stream thumbnails
* keep checkboxes square

### Documentation

* rebuild the GitHub page, with a before/after comparison
* add CLAUDE.md, listing the pages and where their rules live
